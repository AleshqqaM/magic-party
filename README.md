# Волшебная вечеринка

Детская игра-одевалка для браузера: выбрать куклу, нарядить её, украсить комнату и устроить праздник.
Работает без установки и интернета после загрузки: обычные HTML, CSS и JavaScript.

Сайт: https://aleshqqam.github.io/magic-party/

## Как обновить
Перетащите изменённые файлы на страницу репозитория (Add file → Upload files) и нажмите Commit.
После изменения файлов увеличьте номер `?v=` в `index.html`, чтобы телефоны не брали старую версию из кэша.

## Где что
- `content.js` — куклы, наряды, украшения, питомцы и фразы голоса. Новый цвет или предмет — одна строка.
- `art.js` — рисунки (SVG): фасоны, причёски, предметы.
- `audio.js` — звуки, музыка праздника и голос.
- `game.js` — экраны, сохранение, кнопки.
- `style.css` — оформление.
